Hesabchi (حسابچی) 📊📱

Hesabchi is an intuitive, open-source personal financial management Android application designed to help users track expenses, manage bank accounts, set budgets, and stay in full control of their personal finances.

✨ Key Features ->

    💳 Account & Card Management: Register bank accounts/cards with initial balances. Auto-calculate balances based on your transactions. (Supports all Iranian banks).

    💸 Transaction Tracking: Easily log income, expense, and transfer transactions between accounts.

    🏷️ Custom Categories: Categorize transactions with customizable colors and icons. Filter by income, expense, or all categories.

    🎯 Budgeting System: Set monthly spending limits per category to control habits and avoid overspending.

    📜 Debt & Loan Tracking: Keep track of debts and installments—manage total amounts, installment counts, remaining balances, and payment schedules.

    ⏰ Transaction Reminders: Set custom daily alarm notifications so you never forget to log your daily expenses.

    📊 Analytics & Overview: View financial summaries and balance ratios daily, weekly, or monthly in both detailed and aggregated formats.

    💾 Data Backup & Restore: Export full data backups to a file and restore them whenever needed to keep your financial records secure.

🛠️ Tech Stack & Requirements ->

    Platform: Android Mobile

    Language: Kotlin

    Architecture: Clean Architecture, but I didn't know what it means when I built this app
